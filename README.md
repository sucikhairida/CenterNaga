# CenterNaga

CenterNaga utilizes a distributed architecture to facilitate real-time data decision-making via a central control hub and processing engine.

With CenterNaga, you get a lightweight tool that stays out of your way.

**What you get**

- CenterNaga utilizes a distributed architecture
- to facilitate real-time data decision-making
- via a central control hub

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/CenterNaga.git`
2. `cd CenterNaga`
3. Install in editable mode: `pip install -e .`

## Configuration

CenterNaga is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
